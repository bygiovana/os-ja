OS JÁ — sistema de ordens de serviço para oficina mecânica
==========================================================

COMO ABRIR
  Clique no atalho "OS Já" da área de trabalho ou do menu Iniciar.
  O endereço é http://localhost:7300

O QUE FOI INSTALADO
  C:\Program Files\GestaoOS     programa (sistema, Node.js, PostgreSQL)
  C:\ProgramData\GestaoOS       dados: banco, config.env, logs e backups

  Dois serviços do Windows iniciam junto com o computador:
    OS Já             (GestaoOS)        o sistema
    GestaoOS-Banco                      o banco de dados PostgreSQL

CONFIGURAÇÃO
  Edite C:\ProgramData\GestaoOS\config.env (abra o Bloco de Notas como administrador).
  Ali ficam o nome e os dados da oficina que saem na OS impressa.
  Depois de salvar, reinicie o serviço: no PowerShell como administrador,
      Restart-Service GestaoOS

CELULARES DOS MECÂNICOS E OUTROS COMPUTADORES
  1. No menu Iniciar, abra "OS Já — Liberar celulares" e confirme como administrador.
     Ele cria usuário e senha (anote!), libera a porta 7300 no firewall só para redes
     privadas e abre a tela Equipe com o QR code.
  2. Em Equipe, cadastre os mecânicos.
  3. No celular (mesmo Wi-Fi), escaneie o QR code, entre com usuário e senha e use
     "Adicionar à tela inicial". Cada mecânico escolhe o próprio nome no primeiro acesso.
  A rede do Windows precisa estar como PRIVADA (Configurações > Rede e Internet).
  Para voltar a usar só neste computador: no config.env troque HOST=0.0.0.0 por
  HOST=127.0.0.1 e rode  Restart-Service GestaoOS

BACKUP
  PowerShell como administrador:
      $env:PGPASSWORD = ((Get-Content C:\ProgramData\GestaoOS\config.env | Select-String 'DATABASE_URL').ToString() -replace '.*oficina:(.*)@.*','$1')
      & "C:\Program Files\GestaoOS\pgsql\bin\pg_dump.exe" -h 127.0.0.1 -p 55433 -U oficina -Fc -f "C:\ProgramData\GestaoOS\backups\oficina-$(Get-Date -f yyyy-MM-dd).dump" oficina
  Copie a pasta de backups para um pendrive ou nuvem com frequência.

PROBLEMAS
  Logs em C:\ProgramData\GestaoOS\logs (instalacao.log, GestaoOS.*.log, banco-*.log).

DESINSTALAR
  Configurações > Aplicativos > OS Já > Desinstalar.
  Os dados em C:\ProgramData\GestaoOS são mantidos. Apague a pasta manualmente para remover tudo.
